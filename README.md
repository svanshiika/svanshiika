## Featured Projects

### 1. Prediction of Employment Rates

Machine learning project using **real-world Irish government employment data** to understand and predict employment rates across different demographic groups.

**What I worked on:**
- Analysed 4,320+ records of real-world data
- Performed data analysis and preprocessing
- Built supervised and unsupervised machine learning models
- Used Regression and Clustering techniques
- Applied Linear Regression, Gradient Boosting, K-Means and Agglomerative Clustering
- Used Random Forest for feature selection

**Result:**
- Achieved an **R-square of 0.89** with Gradient Boosting
- Achieved an **MAE of 3.75**
- Identified Education Attainment, Age Group and Gender as the strongest predictors

[View Project](https://github.com/svanshiika/Prediction-of-Employment-Rates)
